# Tiara Febrianie - Personal Portfolio 🚀

Personal website and developer portfolio built with modern HTML5, Tailwind CSS, and Lucide Icons, hosted on **GitHub Pages**.

🔗 **Live Site URL (Once Deployed):** `https://tiara082.github.io`

---

## 📂 Cara Deploy ke GitHub Pages (100% Gratis)

### Langkah 1: Buat Repository di GitHub
1. Buka [github.com/new](https://github.com/new).
2. Di bagian **Repository name**, ketik persis:
   ```text
   tiara082.github.io
   ```
   *(Harus `tiara082.github.io` agar langsung menjadi root website kamu)*.
3. Pastikan memilih **Public**.
4. Biarkan opsi lainnya default, lalu klik **Create repository**.

### Langkah 2: Upload File Ini ke GitHub
Buka terminal / PowerShell di folder ini (`tiara082.github.io`) lalu jalankan perintah berikut:

```bash
git init
git add .
git commit -m "feat: initial release of portfolio website"
git branch -M main
git remote add origin https://github.com/tiara082/tiara082.github.io.git
git push -u origin main
```

*(Atau kamu juga bisa drag & drop file `index.html` langsung lewat browser di halaman GitHub repository-mu)*.

### Langkah 3: Selesai!
GitHub Pages akan otomatis mengenali repositori `tiara082.github.io`.
Tunggu sekitar 1–2 menit, lalu buka di browser:
👉 **https://tiara082.github.io**
